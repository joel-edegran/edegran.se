# edegran.se

Personal website for edegran.se.

## Tech Stack

* **Build Tool:** Vite
* **Templating:** Pug via Vituum
* **Styling:** Stylus & Pico CSS
* **Formatting:** Prettier with Pug plugin

## Prerequisites

* Node.js (v18+ recommended)
* pnpm

## Scripts

```bash
# Start local development server
pnpm dev

# Build for production
pnpm build

# Preview production build locally
pnpm preview
```
